# Testing
- Treat tests as part of every feature, not an afterthought.
- Preserve existing tests and investigate failures rather than weakening assertions.
- Cover normal behavior, edge cases, malformed input, state transitions, and failure recovery.
- Prefer deterministic tests and small fixtures.
- Run the full relevant suite before declaring work complete.

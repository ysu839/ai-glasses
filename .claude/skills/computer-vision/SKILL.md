# Computer Vision
- Optimize for real-time processing and predictable latency.
- Keep camera/input, preprocessing, inference, tracking, and interpretation separable.
- Record confidence and uncertainty rather than inventing detections.
- Handle empty, malformed, low-light, and dropped-frame inputs safely.
- Test geometry, tracking identity, frame timing, and failure behavior.

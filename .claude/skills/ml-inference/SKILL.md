# ML Inference
- Prefer measurable model quality and latency over hype.
- Separate model loading, preprocessing, inference, and postprocessing.
- Track model version, device target, confidence thresholds, and resource usage.
- Never silently substitute fabricated model outputs.
- Add evaluation cases and regression tests when changing inference behavior.

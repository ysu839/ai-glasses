# Git Workflow
- Inspect status and relevant history before making changes.
- Keep commits focused and descriptive.
- Never overwrite unrelated user work.
- Do not commit secrets, generated caches, local environments, or large artifacts unless explicitly required.
- Use branches and pull requests for risky or substantial changes when appropriate.

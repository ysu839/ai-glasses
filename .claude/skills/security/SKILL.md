# Security
- Never commit secrets, tokens, private keys, or credentials.
- Validate untrusted inputs and constrain external tool actions.
- Use least privilege for integrations and services.
- Treat camera, microphone, location, identity, and user data as sensitive.
- Prefer secure defaults and explicit permissions.
- Review dependencies and generated code before introducing them.

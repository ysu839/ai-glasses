# Debugging
- Reproduce the failure before changing code when practical.
- Inspect logs, stack traces, state, inputs, and recent changes.
- Identify the root cause rather than masking symptoms.
- Make the smallest safe fix.
- Add a regression test for confirmed bugs.
- Re-run affected and full tests after the fix.

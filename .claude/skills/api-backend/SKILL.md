# API Backend
- Define explicit request/response schemas and version public interfaces.
- Validate inputs and return actionable errors.
- Keep business logic separate from transport handlers.
- Make network calls resilient with timeouts and bounded retries.
- Never log secrets or unnecessary sensitive user data.
- Add integration tests for important API contracts.

# Edge Hardware
- Isolate hardware adapters behind testable interfaces.
- Never hard-code assumptions about devices when configuration can express them.
- Handle disconnects, unavailable peripherals, resource limits, and shutdown safely.
- Keep device-specific code separate from core reasoning and world-model logic.
- Provide mocks or simulators for development without physical hardware.

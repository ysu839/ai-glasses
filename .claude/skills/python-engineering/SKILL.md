# Python Engineering
- Follow the repository's existing Python version, tooling, and style.
- Prefer clear modules, type hints, small functions, and explicit error handling.
- Avoid unnecessary dependencies.
- Preserve public interfaces unless migration is intentional.
- Add or update tests for behavior changes.
- Run the relevant test suite after changes.
